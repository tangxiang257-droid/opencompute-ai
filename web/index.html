设备接入与 API

将可信私有网络中的 CPU 设备注册为 Worker

接入一台新设备

在目标设备上运行 Worker Agent

  1. 在服务端配置 OPENCOMPUTE_JOIN_KEY（至少 16 位）。
  2. 在可信私有网络中启动服务端，并确认设备可访问 API 地址。
  3. 在设备上安装仓库依赖，然后运行 Worker Agent。
  4. 返回本页刷新设备列表，确认节点在线。
OPENCOMPUTE_API_URL=http://127.0.0.1:8000 OPENCOMPUTE_JOIN_KEY=替换为服务端加入密钥 python -m cluster_v03.worker --name my-cpu-worker

API 快速参考

管理员密钥使用 X-Admin-Key 请求头

GET /health GET /v0.3/status POST /v0.3/tasks GET /v0.4/models GET /v0.5/status POST /v0.5/requests

Worker 节点使用 X-Join-Key 完成注册，之后使用节点令牌发送心跳、领取任务和提交结果。不要把管理员密钥或节点令牌写入公开网页、代码仓库或 URL。

打开 FastAPI 交互式 API 文档 ↗
安全边界：当前版本适合本机或可信局域网研究测试，不是公网多租户服务。默认 Docker Compose 仅绑定 127.0.0.1。不要直接把未启用 TLS、强身份认证和资源隔离的 Worker API 暴露到互联网。
