# OpenCompute AI v0.7.2 单卡 Qwen2 推理验证

在装有 NVIDIA GPU 的设备上，从本地 Safetensors 权重读取 Qwen2，执行 FP32 前向计算和使用 KV 缓存的贪心解码。该入口适合验证单张卡的权重加载和计算，当前通过本地命令运行。

1. 按照 [PyTorch 安装说明](https://pytorch.org/get-started/locally/) 安装与本机驱动兼容的 CUDA 版 PyTorch，再安装项目依赖。
2. 准备可信的 Qwen2 模型目录。目录需包含 `config.json` 及 `model.safetensors`，也支持索引描述的 Safetensors 分片。
3. 使用该模型对应的 tokenizer 把输入文本转换为 token ID，然后运行以下命令。示例 ID 仅用于检查执行链路。

```powershell
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -m compute.qwen2_single_device --model ./models/qwen2 --device cuda:0 --ids 1 7 2 --new-tokens 16
```

输出包含执行设备、生成的 token ID 和加载权重及生成所用的时间。可使用同一组 ID 和 `--device cpu` 在 CPU 上运行。模型为单文件时可传入 `--expected-sha256` 核对权重。

CUDA 入口会检查指定设备和可用显存，失败时直接退出。每次运行接受 1 至 512 个输入 token、最多生成 64 个 token。普通 CI 检查 CPU 路径与本地 Safetensors 加载，检测到 CUDA 设备时另运行 CPU/CUDA logits 和 token 一致性测试。

```powershell
python -m unittest discover -s tests -p test_qwen2_single_device_v072.py -v
```
