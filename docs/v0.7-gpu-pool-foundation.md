# OpenCompute AI v0.7 GPU pool foundation

## Scope

This change adds NVIDIA GPU discovery, authenticated Worker inventory reporting,
SQLite persistence, an administrator-only inventory endpoint, and a dashboard
view. It does not yet schedule GPU work, reserve VRAM, execute model layers on
GPUs, or combine VRAM across machines.

## NVIDIA Worker requirements

- Install a supported NVIDIA display/compute driver on the host.
- Confirm nvidia-smi runs and lists the intended GPU(s).
- Run the existing Worker agent on the host (or in a container with NVIDIA
  Container Toolkit and GPU passthrough configured).
- The Worker detects GPUs with a fixed, read-only nvidia-smi query and reports
  the inventory every 30 seconds using its node token. The administrator key
  is never sent to the Worker.

Run a local detection check with:

    python -m cluster_v07.detection --json

## API

- POST /v0.7/nodes/{node_id}/gpus — Worker-authenticated inventory report
  using X-Node-Token.
- GET /v0.7/gpus — administrator-authenticated inventory using X-Admin-Key.

The API bounds inventory size and validates memory, utilization, UUIDs, indexes,
vendor/backend labels, and supported precision labels. A node's reported GPU
inventory is replaced atomically, so unplugged devices disappear on the next
report. Online capacity is counted only for nodes with fresh heartbeats and
recent GPU telemetry.

## Trust and deployment boundary

GPU telemetry is self-reported and is marked self_reported; it is not proof
that a physical GPU is genuine or exclusively available. GPU scheduling must
not rely on these values as trusted attestation. This phase does not expose a
public no-key registration path: existing v0.3 Worker registration still uses
the configured Join Key and is intended for a trusted network. Public automatic
admission, abuse controls, sandboxing, and GPU task execution require separate
security work before public deployment.

## CI coverage

tests/test_gpu_pool_v07.py covers API authentication, node-token reporting,
validation, online/offline aggregation, inventory replacement, and deterministic
parsing of mocked nvidia-smi output. CI does not require a physical GPU.
