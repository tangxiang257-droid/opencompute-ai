# 一键加入算力池：浏览器模式与原生客户端的边界

版本：v0.8.1 + 体验增强（2026-11-12）。这一变更仅新增网页加入入口，不代表公共 CPU 已获得用户任务或开放了 GPU 模型推理。

## 面向用户

访问 `/join`，点击「立即加入 CPU 验证池」。网页在用户主动点击后：

1. 检查安全上下文、Web Worker、浏览器报告的逻辑处理器数和估算内存；若无内存信息，不猜测真实硬件参数，提示使用桌面 Worker。
2. 启动同源 Dedicated Web Worker，仅用一个线程执行固定的 48×48 矩阵校验；它访问既有 `/v0.8/public/challenge`、`/join` 和 `/heartbeat`，无管理员密钥、加入密钥与文件权限。
3. 资源达标时用服务端颁发的节点 Bearer 凭证完成自动注册；令牌仅保存在 Worker 内存，不传递给页面、不写入 LocalStorage。
4. 每约 20 秒执行一次下一轮验证；页面休眠可能导致定时器延后、节点过期；网络短暂中断可重新接入。
5. 点击「退出」时，Worker 尝试使用自己的节点令牌调用新增 `POST /v0.8/public/leave` 立即注销 CPU 会话。若页面关闭太快或断网，已有 90 秒在线超时机制使其自然离线。

站点首页和「设备接入与 API」页也提供一键按钮，并保留现有 Python Worker 下载与手动命令供 GPU 测试及不支持的浏览器使用。

## 准确的功能边界

| 加入方式 | 目前已实现 | 尚未实现 |
| --- | --- | --- |
| 浏览器一键 CPU | 自动资源检查、服务端挑战、注册、心跳、退出 | 公共 CPU 用户任务领取、真实 LLM 推理、浏览器关闭后持续贡献 |
| 原有本机 CUDA Python Worker | 免共享密钥自动入池、GPU 资源上报、受限 GPU 矩阵任务领取 | Windows/macOS/Linux 原生一键安装包、NVIDIA 驱动自动配置、公众 Qwen2 推理 |
| 未来 WebGPU | 仅作为候选技术，不纳入本次提交 | 将 WebGPU 设备伪装成 CUDA GPU、在浏览器内执行现有 CUDA Scheduler |

网页在不获得系统安装授权的情况下不能静默部署或运行原生软件。WebGPU 的 GPU 计算能力受浏览器与安全上下文限制，无法作为当前 CUDA/PyTorch 的直接替代。浏览器提供的 `navigator.deviceMemory` 是模糊估值，不是硬件远程证明。浏览器 Worker/Service Worker 也不能保证网页关闭后永久运行。

## 下一阶段：真正接近一键贡献 GPU 算力

- P1：制作官方签名的 Windows 轻量客户端，允许用户主动安装并明确勾选「开机启动 / 仅空闲运行 / GPU 功耗上限 / 可随时暂停」。驱动与 PyTorch 依赖检测后只展示必要授权步骤，不在网页中静默提权执行 shell。
- P2：增加可升级版本、受控下载和 SHA256/发布者签名核验，客户端自动从用户当前站点读取 API 地址并协商准入，无须用户输入管理密钥。移动端不自动下载二进制。
- P3：有界浏览器 CPU 真实任务队列 / WebGPU 算子任务，必须有任务确认与隔离、资源上限和正确性复核，不使用任何用户上传的可执行代码。
- P4：把经验证的 GPU 推理任务开放给明确同意、权限隔离的节点；未授权的陌生节点不得直接接收用户敏感提示词或未加密中间状态。

### 安全要求

- 网页/原生客户端安装及资源使用必须主动授权；一键加入不代表无限制占用全部 CPU/GPU。
- 公开 Worker 仅执行固定白名单任务，不允许自动运行用户上传的 Python、shell 脚本或不可信 pickle。
- 退出接口要求独立 Bearer 节点密钥，且只可撤销 CPU 验证会话，不能取消 GPU 正在执行的租约。
- 密钥仅经 HTTPS 和同源 API 传输；不在 URL、日志或页面状态中显示。
- 首页公开的状态和「加入」按钮不要求管理员登录；现有管理员 API 仍严格需要 X-Admin-Key。
