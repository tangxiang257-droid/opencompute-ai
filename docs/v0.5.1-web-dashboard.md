# OpenCompute AI v0.5.1 Web 控制台

## 访问网页

默认 Docker 镜像会把 `web/index.html` 打包进容器，并由 FastAPI 根路径提供页面：

    http://127.0.0.1:8000/

启动前配置管理员密钥和 Worker 加入密钥：

    export OPENCOMPUTE_ADMIN_KEY='至少 16 位的随机管理员密钥'
    export OPENCOMPUTE_JOIN_KEY='至少 16 位的随机节点加入密钥'
    python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000

或在仓库根目录配置环境变量后运行：

    docker compose up --build -d

默认 Compose 端口仅绑定到本机回环地址。控制台顶部输入 `OPENCOMPUTE_ADMIN_KEY` 对应的管理员密钥后，可以读取集群状态、提交 CPU 测试任务和查看 Qwen2 队列。密钥只保存在当前浏览器标签页的 sessionStorage 中，不会写入 URL。

## 页面功能

- **总览：** 在线节点、CPU 核心、内存、运行任务、集群负载和最近任务。
- **设备节点：** Worker 平台、CPU/RAM、负载、能力标签、心跳和在线状态。
- **任务队列：** 提交 sum、sha256、matmul_checksum 三种白名单 CPU 任务，并查看任务状态与结果。
- **模型中心：** 读取 `GET /v0.4/models` 的模型目录和能力状态。
- **推理实验：** 读取 `GET /v0.5/status` 并向 `POST /v0.5/requests` 提交原始 Token ID。
- **设备接入与 API：** 生成 Worker Agent 命令并查看 API 路由。

## 连接 Worker

在服务端设置 `OPENCOMPUTE_JOIN_KEY`，在 Worker 设备安装仓库依赖后执行（将 URL 改为服务端在可信私有网络中的地址）：

    export OPENCOMPUTE_API_URL='http://SERVER_PRIVATE_IP:8000'
    export OPENCOMPUTE_JOIN_KEY='与服务端相同的加入密钥'
    python -m cluster_v03.worker --name my-cpu-worker

当前通用 Worker 只执行 sum、sha256、matmul_checksum 白名单任务。不要将其误认为已支持远程 Qwen2 模型分片推理。

## 安全与功能边界

- 当前控制台使用共享管理员密钥，不包含用户注册、个人账户、角色权限或账单系统。
- Worker 加入密钥允许节点注册；节点令牌用于后续心跳和领取任务。请勿泄露密钥。
- 默认 Compose 只绑定 `127.0.0.1`。如需私有网络访问，应另行配置防火墙、TLS 反向代理、身份认证和访问控制；不要直接将当前 HTTP 服务暴露到公网。
- Qwen2 服务要求服务端预先准备可信本地 bundle；尚未实现远程个人设备参与 Qwen2 推理、常驻 Rank、流式 Token 或多租户隔离。
